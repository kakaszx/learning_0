Exemplos de Tags HTML Comuns

  • <h1> a <h6>: Usadas para títulos e subtítulos, onde <h1> é o mais importante e <h6> o menos importante.
  • <p>: Define um parágrafo de texto.
  • <a>: Cria um link para outra página ou recurso.
  • <img>: Insere uma imagem na página.
  • <div>: Define uma seção ou divisão genérica na página, usada para agrupar outros elementos.
  • <span>: Usado para estilizar uma parte específica do texto dentro de um elemento maior.
  • <ul> e <ol>: Criam listas não ordenadas (com marcadores) e ordenadas (numeradas), respectivamente.
  • <table>: Define uma tabela para organizar dados em linhas e colunas.
